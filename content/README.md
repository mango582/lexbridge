# LexBridge 法律内容填写说明

这个 `content/` 文件夹用来存放团队整理的法律内容。改完文件后，刷新网站（或重新双击“启动网站.bat”）即可看到效果。

请把所有内容文件保存为 UTF-8 编码（记事本或 VS Code 保存时，编码选 UTF-8）。

当前已整理的文件：
- `qa.md`：涉外法律问答知识库（问题、关键词、回答、法律依据、来源、适用地区、更新时间）。
- `compare_china.md` / `compare_usa.md`：中国与美国法律比较（个人信息保护、数据出境、商业秘密、出口管制）。
- `risk.md`：跨境合规风险分析参考规则（高/中/中-高风险检查点）。
- `sources.md`：法规来源清单（效力级别、日期、核心要点）。

> 核心规则（必须遵守）：
> 1. 只写真实、可核验的法律条文与信息，并注明出处与更新时间。
> 2. 找不到可靠资料时，就写“暂缺”，绝不编造法律名称、法条编号或案例。
> 3. 涉及美国时，明确写清是“联邦层面”还是“哪个州”的规定，不要把某一州规定说成全美统一。
> 4. 所有内容只是法律信息参考，不构成法律意见。

## 各文件怎么填

### 1. compare_china.md / compare_usa.md（中国与美国法律比较）

直接写 Markdown 列表即可。中国部分示例：

```markdown
- **立法模式**：……
- **核心机制**：……
- **跨境传输**：……
```

美国部分务必先说明“美国没有全国统一的综合性个人信息保护联邦法”，并区分联邦与各州。

### 2. qa.md（涉外法律问答知识库）

每条问答以一行 `## 问题标题` 开头，多条直接连续往下写：

```markdown
## 个人信息跨境传输
关键词：个人信息, 隐私, 数据出境, PII
适用地区：中国 / 美国（美国各州规定可能不同）
更新时间：2026-11-20
回答：
（在这里写正式、完整的回答，可以多行。）
法律依据：
（写真实法条全称与条文，须可核验；暂无就写：暂缺）
来源：
（写官方来源名称或链接；暂无就写：暂无）
```

说明：

- “关键词”用逗号分隔，用户输入里出现任一关键词就会匹配到这条回答。
- “回答 / 法律依据 / 来源”下面可以写多行，直到下一个字段标题为止。
- 没有可靠依据时，法律依据写“暂缺”、来源写“暂无”，千万不要编造。

### 3. risk.md（跨境合规风险分析 · 参考规则）

放团队整理的合规风险检查点，直接写 Markdown 列表。例如：

```markdown
- 数据跨境：是否涉及个人信息出境，是否需要安全评估……
- 合同与争议解决：……
- 税务与支付：……
```

> 注意：第一版的风险分析结果本身仍是“演示算法”，本文件内容会作为“团队整理的合规参考规则”展示在风险页底部，供用户参考。
